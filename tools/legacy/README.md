# Ferramentas históricas

Esta pasta reúne scripts avulsos que antes estavam na raiz do repositório.
Eles não fazem parte dos comandos oficiais definidos em `package.json`.

- `diagnostics/`: auditorias, verificações e investigações pontuais.
- `queries/`: consultas manuais de dados e integrações.
- `maintenance/`: correções e operações administrativas históricas.
- `tests/`: testes isolados e protótipos.

Antes de executar qualquer script, revise-o e confirme o ambiente de destino.
